## P4: it staged the wrong order, which showed why `loadBefore` exists

All four scenarios of `08` failed. The load order printed in the failure is Harmony, the expansions, RimLogging,
Pickle, **A Dog Said 2, then this mod**. The staging script activates the mods a pass map names before the mod
under test and does not sort by `loadBefore`. With the order reversed, A Dog Said 2 copied its category lists into
its recipes first, and the species were added to lists nobody read: `Ebbb` had 26 recipes and not the peg leg, and
so did `Crebbb` and `Beee`. That is the failure `About.xml`'s `loadBefore` prevents, seen by accident, and it
confirms that the patch does nothing when it runs too late. The pass map now names this mod's own folder first,
which the staging treats as an overlay of the mod under test, so the pass stages the declared order; the request
is `20260925-153755-054-9822`. What the game's own sorting does with `loadBefore` is the game's and is not tested.
