## P3 retry: the game does not log the duplicates, and I had claimed it did

Request `20260925-165238-110-2299`, the retry after the crash (SIGSEGV 139) of the first try, which did not recur:
`exitReason: failed`, 0 of 1. The start-up wait worked, the scenario reached its assertions, and failed on the one that
was **wrong**: no line "Adding duplicate ThingDef name" is in the log, and none of any other kind about a defName
defined twice. The log holds 11 errors and warnings: the Steam API warning, and the original's `wildness` values
"don't correspond to any field in type RaceProperties", nine times.

**The mistake was mine.** On 2026-09-24 I read `Verse.DefDatabase.Add`, which does log "Adding duplicate", and
concluded that the game reports a defName that two mods define and renames the later one. I did not read its caller.
`AddAllInMods` walks the mods by priority and then load order and, when a defName already exists, **removes the earlier
def without logging anything** before adding the later one. So the later mod silently replaces the earlier, and only a
duplicate inside a single mod is an error. The comment the port already carried in `About.xml`, "resolves a duplicate
defName by load order and logs nothing", was correct, and on that same day I rewrote it wrongly, along with the notes,
the feature and the pass map that repeated the claim. The run is what showed it.

What this means for the mod: with both enabled, the species of the mod that loads later silently replace the other's.
Loaded first, the original would overwrite this port with the definitions that fail on `wildness`, so every animal
tames for almost nothing again, without one line in the log naming the conflict. That is why the incompatibility is
declared, and it is worth declaring more, not less.

Still to do once the three queued passes are done, since they stage `Mod/` and the companion: put the `About.xml`
comment back to what is true, and rewrite `05` to assert the silent replacement, that is which mod owns each species
in the running game and that both mods define it, with the original's own `wildness` errors as the visible symptom.
The retry's evidence is in `Tests/Pickle/Evidence/fix-p3-retry/`, cut to the text files.
